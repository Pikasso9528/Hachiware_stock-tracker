===============================================================================
台股強勢股分析儀表板 - Skills 使用說明
===============================================================================

這份文件說明 .claude/skills/ 底下的 11 個技能（skill）怎麼用：什麼時候該用
哪一個、截圖要放在哪裡、實際會執行什麼指令。所有技能底層都是呼叫同一支
data_processor.py，差別只在於用 --category / --pin / --unpin 指定範圍。

技能不是可直接執行的程式，是給 Claude Code 讀的操作說明。使用方式有兩種：
  (1) 直接跟 Claude 說技能名稱（例如 "update-pool" 或 "update-pool 2026-08-28"），
      Claude 會讀取對應的 SKILL.md 並自動執行底層指令。
  (2) 自己在 screenshots/ 目錄下開終端機，直接執行 SKILL.md 裡列出的
      python data_processor.py ... 指令，不透過 Claude。
兩種方式效果完全一樣，因為 Claude 也只是在跑同一支指令。

-------------------------------------------------------------------------------
1. 專案結構總覽
-------------------------------------------------------------------------------

screenshots/                       <- 這個目錄本身（data_processor.py 所在處）
  focus/<日期>/                    焦點監控 清單型截圖
  alpha/<日期>/                    alpha 動能 清單型截圖
  pullback/<日期>/                 回檔型 清單型截圖
  super/<日期>/                    當日 Super 個股詳細頁截圖（強度資料唯一來源）
  stock_future_top/<日期>/         量大股期排行榜截圖（可多張，捲動拍攝）
  group/<日期>/overall.jpg         族群清單模式總覽截圖（檔名固定）
  group/<日期>/<任意檔名>.jpg      族群個別成分股清單模式截圖（選用，可多張）
  update/                          監控股池補漏截圖，非日期資料夾，檔名建議用
                                    股票代號開頭（例如 8358.png），但手機截圖
                                    預設檔名（S__xxxxx_0.jpg）也可以直接放，
                                    程式會自動用截圖內容 OCR 辨識代號
  tracker_db.json                  所有股票的歷史強度、監控股池狀態（持久化資料）
  docs/today_summary.json          目前最新一次輸出，前端儀表板讀這個檔案
  docs/history/<日期>.json         每個日期的分頁快照，供前端「資料日期」下拉選單切換

日期資料夾格式一律為 YYYY-MM-DD（例如 2026-08-28）。

-------------------------------------------------------------------------------
2. 快速開始：一天的標準流程
-------------------------------------------------------------------------------

  步驟 1: 跟 Claude 說 "create_files"（或 "create_files 2026-08-30"）
          -> 在 focus/alpha/pullback/super/stock_future_top/group 底下
             建立當天的空資料夾。

  步驟 2: 把當天截圖分別存進對應資料夾：
          - focus/<日期>/          焦點監控清單截圖
          - alpha/<日期>/          alpha 動能清單截圖
          - pullback/<日期>/       回檔型清單截圖
          - super/<日期>/          個股詳細頁截圖（相對強度表）
          - stock_future_top/<日期>/  量大股期排行榜截圖
          - group/<日期>/overall.jpg  族群清單模式總覽截圖
          - group/<日期>/其他檔名.jpg 各族群成分股清單截圖（選用）
          - update/                監控股池補漏截圖（選用，非日期資料夾）

  步驟 3: 跟 Claude 說 "update-all"（或 "update-all 2026-08-30"）
          -> 依序處理全部七個分頁，一次到位。

  步驟 4: 打開 docs/today_summary.json 所在的網頁（本機預覽或 GitHub Pages），
          確認資料正確。

如果只有某一類截圖更新（例如只多拍了 alpha 動能的圖），不需要跑 update-all，
直接跟 Claude 說 "update-alpha" 就好，速度更快、也不會動到其他分頁的資料。

-------------------------------------------------------------------------------
3. 七個分頁對照表（UI 顯示名稱 / 內部代號 / 對應技能）
-------------------------------------------------------------------------------

  UI 顯示名稱      內部代號 (--category)    對應技能            是否依日期切換
  --------------   ---------------------    -----------------   ---------------
  Focus            focus                    update-focus        是
  alpha power       alpha                   update-alpha         是
  pullback          pullback                 update-pullback      是
  Super Man         super                    update-super         是
  stock future      stock_future             update_stock_future  是
  Circle group      group                    update-group         是
  watchout pool     pool                     update-pool          否（累加型）

  除 watchout pool 之外，其餘六個分頁的資料都會隨著網頁上「資料日期」下拉
  選單切換而改變；watchout pool 是累加型分頁，一律顯示最新狀態，不受日期
  切換影響。

-------------------------------------------------------------------------------
4. 各技能詳細說明
-------------------------------------------------------------------------------

--- 4.1 create_files -----------------------------------------------------
用法：create_files [日期]（沒帶日期預設今天）
指令：mkdir -p focus/<日期> alpha/<日期> pullback/<日期> super/<日期>
             stock_future_top/<日期> group/<日期>
作用：建立當天六個分類資料夾底下的日期子資料夾，供你把截圖放進去。
      只建空資料夾，不會動任何截圖檔案；不會建立 update/ 的日期子資料夾
      （update/ 本身不分日期）。

--- 4.2 update-focus -------------------------------------------------------
用法：update-focus [日期]
指令：python data_processor.py --category focus --date <日期>
作用：掃描 focus/<日期>/ 清單截圖，辨識當日名單，更新「Focus」分頁。
      強度徽章／五日星星沿用既有歷史資料（來自 update-super/update-pool），
      不是這裡算出來的。

--- 4.3 update-alpha -------------------------------------------------------
用法：update-alpha [日期]
指令：python data_processor.py --category alpha --date <日期>
作用：同 update-focus，處理 alpha/<日期>/，更新「alpha power」分頁。

--- 4.4 update-pullback -----------------------------------------------------
用法：update-pullback [日期]
指令：python data_processor.py --category pullback --date <日期>
作用：同 update-focus，處理 pullback/<日期>/，更新「pullback」分頁。

--- 4.5 update-super ---------------------------------------------------------
用法：update-super [日期]
指令：python data_processor.py --category super --date <日期>
作用：掃描 super/<日期>/ 個股詳細頁截圖，這是全站強度資料的唯一真實來源：
      - 更新每檔股票的相對強度歷史（影響所有分頁顯示的當日強度／五日星星）
      - 當日出現在 super 截圖的股票，若尚未在監控股池中會自動加入
      - 更新「Super Man」分頁
      建議順序：若同一天要處理多個分頁，先跑這個，其他分頁的強度才會是最新的
      （或直接用 update-all，順序已經處理好）。
      若截圖出現 [WARN] 無法辨識股票代號：不要請使用者手動改檔名，改由 Claude
      直接用 Read 工具讀圖，視覺辨識出代號，把該截圖複製到 update/<代號>.<副
      檔名>，重跑 update-pool 讓資料併入，確認生效後刪掉原本辨識失敗的檔案。

--- 4.6 update_stock_future ---------------------------------------------------
用法：update_stock_future [日期]
指令：python data_processor.py --category stock_future --date <日期>
作用：掃描 stock_future_top/<日期>/ 量大股期排行榜截圖（可多張，捲動拍攝），
      辨識每列印出的「排名」數字、股票代號與期漲幅(%)，依排名數字（不是檔名
      或掃描順序）由小到大排序，更新「stock future」分頁。目前只處理「多方」
      畫面。截圖檔名／拍攝順序不需要對應畫面捲動順序，程式一律依畫面上實際
      的排名數字排序。
      代號欄是小字灰階數字，偶爾會有形近數字誤判（例如 4↔8），且誤判後的
      代號可能剛好也是別支股票的有效代號、驗證抓不出來——只有顯示的公司
      名稱跟代號兜不起來才看得出問題。若使用者反映某列名稱／代號兜不起來，
      直接用 Read 工具讀圖核對，確認後手動修正 docs/history/<日期>.json（與
      docs/today_summary.json，若該日期是最新日期）。

--- 4.7 update-group -----------------------------------------------------------
用法：update-group [日期]
指令：python data_processor.py --category group --date <日期>
作用：
      - 解析 group/<日期>/overall.jpg（清單模式，不是熱力圖色塊模式），
        取漲幅 > 0% 的前 10 個族群，更新「Circle group」分頁
      - 掃描同資料夾內其他截圖（各族群成分股清單模式），依標題比對出所屬
        族群，附上該族群前 10 大個股排行
      - 前端點擊某個族群列可展開看成分股排行；沒有明細截圖的族群會顯示
        "No more Information, please update"
      注意：截圖務必是「清單模式」（左上角 ☰ 圖示切換），不是熱力圖色塊模式，
      辨識穩定度差很多。
      若某族群名稱比對信心不足或明細截圖標題辨識不出所屬族群：只要 OCR 出來
      的原始文字是合理、看得懂的真實產業名稱（不是亂碼），Claude 會直接把它
      加進 data_processor.py 的 GROUP_SECTOR_WHITELIST 並重跑，不需要先問過
      使用者；只有文字明顯是亂碼、判斷不出應該對應哪個名稱時才需要人工確認。

--- 4.8 update-pool -----------------------------------------------------------
用法：update-pool [日期]
指令：python data_processor.py --category pool --date <日期>
作用：
      - 掃描 update/ 補漏截圖，更新對應股票的相對強度歷史（檔名建議用代號，
        但非代號格式的檔名也會自動 OCR 辨識代號）
      - 監控池中「今天完全沒有 super/update 截圖」的股票，標記為未更新（❓）
      - 套用「連續5個交易日無偏強/極強 -> 標示警示，隔天仍未轉強才正式剔除」
        的規則（觀察中/pinned 的股票不受此規則影響，見第5節）
      - 更新「watchout pool」分頁（不寫入 docs/history/，一律最新狀態）
      建議每天最後才跑這個分頁（或直接用 update-all），確保剔除判斷用的是
      當天最終、完整的強度資料。
      若 update/ 裡有截圖 [WARN] 無法辨識股票代號：不要請使用者手動改檔名，
      改由 Claude 用 Read 工具讀圖辨識代號，複製一份成 update/<代號>.<副檔
      名>，重跑確認生效後，把原本那張辨識失敗、檔名非代號格式的截圖從
      update/ 刪除（內容已保留在新檔案裡，留著只會每次重跑都重複跳出同樣
      的警告）。
      若出現 [WARN] ...都對應到代號 X，兩張的相對強度表會合併：代表
      update/ 裡有兩張截圖（常見情況是舊的代號檔名截圖 + 新拍的手機預設檔
      名截圖）辨識出同一支股票，程式會自動合併兩張的強度表（不會互相蓋掉
      漏資料），但建議清理：確認較新那張涵蓋到最新日期後，把它改名成代號
      檔名取代舊檔，舊檔改成 .bak 副檔名保留備份、不再參與掃描。

--- 4.9 pin-stock -------------------------------------------------------------
用法：pin <股票代號>（例如 pin 2308），可選 --date 指定納入日期
指令：python data_processor.py --pin <股票代號> [--date <日期>]
作用：手動把一檔股票加入監控股池，並標記為「觀察中」——不受5日剔除規則
      影響，不需要它先出現在 super 截圖中。已在池中的股票只是補上標記。
      pin 本身不提供強度資料，每日強度仍要靠 update-super 或
      update/<代號> 截圖更新。

--- 4.10 unpin-stock ----------------------------------------------------------
用法：unpin <股票代號>（例如 unpin 2308）
指令：python data_processor.py --unpin <股票代號>
作用：取消某股票的「觀察中」標記，恢復套用一般5日剔除規則。不會直接把它
      從池中移除，只是拿掉特殊保護，之後表現不佳一樣會被正常剔除。

--- 4.11 update-all -----------------------------------------------------------
用法：update-all [日期]
指令：python data_processor.py --date <日期>
作用：依序執行 update-focus -> update-alpha -> update-pullback ->
      update-super -> update_stock_future -> update-group -> update-pool，
      一次更新全部七個分頁。順序內建處理好了，不需要自己記順序。
      只有某一類截圖更新時，改用對應的單一技能即可，不必每次都跑這個。

-------------------------------------------------------------------------------
5. 監控股池的「觀察中」(pinned) 機制
-------------------------------------------------------------------------------

監控股池預設規則：連續5個交易日都沒有出現偏強/極強 -> 標示警示 -> 隔天
仍未轉強就正式剔除。

如果有股票你想長期盯著、不想被這條規則自動清掉，用 pin-stock 把它標記為
「觀察中」；前端會在股票名稱旁顯示 📌 圖示。想取消保護，用 unpin-stock。

觀察中股票的每日強度資料來源跟一般監控池股票完全一樣（super 截圖或
update/ 補漏截圖），pin 這個動作只影響「會不會被剔除」，不會自動生出
強度資料——如果都沒有截圖來源，當日強度會顯示❓，但依然留在池中。

-------------------------------------------------------------------------------
6. 常見問題
-------------------------------------------------------------------------------

Q: 為什麼 update/ 資料夾裡的截圖沒有生效？
A: 檢查是不是截圖內容真的模糊到連 OCR 都讀不出代號（會印出 [WARN] 並略過該
   檔）。手機截圖預設檔名（S__xxxxx_0.jpg）會先自動用截圖內容 OCR 辨識代號，
   不需要手動改檔名；真的辨識失敗時，改由 Claude 用視覺讀圖辨識代號、複製
   成正確檔名補上，不需要使用者自己動手改檔名（細節見 4.5／4.8 節）。
   同樣的道理也適用於 super/<日期>/ 個股詳細頁截圖代號辨識失敗的情況——
   注意在 super/<日期>/ 資料夾裡改檔名沒有用，那個資料夾的掃描邏輯完全不看
   檔名，只有 update/ 資料夾才會信任檔名代號。

Q: update-group 的族群名稱/個股名稱亂碼怎麼辦？
A: 確認截圖是「清單模式」（☰ 圖示），不是熱力圖色塊模式；名稱亂碼多半發生
   在截圖最下面被 App 內浮動小徽章（例如直播中）擋住的那一列，這是截圖本身
   的限制，換個滑動位置重截圖會比重跑指令更有效。若某個族群名稱明顯錯誤且
   確實排在前10名內，且 OCR 出來的原始文字是看得懂的真實產業名稱（不是
   亂碼），Claude 會直接把它加進 data_processor.py 的 GROUP_SECTOR_WHITELIST
   並重跑，不需要先問過使用者。

Q: update_stock_future 排行榜的某一列股票名稱跟代號看起來兜不起來怎麼辦？
A: 代號欄是小字灰階數字，OCR 偶爾會形近誤判（例如 4↔8），且誤判後的代號
   可能剛好也是別支股票的有效代號，程式本身抓不出這種錯誤。反映給 Claude
   後會直接讀圖核對正確代號，手動修正 docs/history/<日期>.json（若該日期
   是最新日期，docs/today_summary.json 也要一併更新或重新輸出）。

Q: 為什麼想用 ./update-pool 這樣直接執行卻不行？
A: 技能是給 Claude 讀的操作說明文件，不是可執行檔。直接跟 Claude 說技能
   名稱，或自己執行 SKILL.md 裡列出的 python data_processor.py 指令。

Q: 想只更新某一個分頁，但又不確定要用哪個技能？
A: 對照第3節的表格，找到你更新的截圖對應哪個 UI 分頁，就用同一列的技能。

Q: TWSE/TPEX 三大法人資料抓取失敗（[WARN] ... 520 Server Error）？
A: 通常是對方伺服器暫時性問題，重新執行一次指令通常就會成功。
